# Research notes

These are working documents, not the shipped data. Each one was written by AI coding agents
(Claude Code) under the direction of Yang-Joon Kim on the date in its header, over three days from
2026-09-06 to 2026-09-08, and each carries the same header saying so. They record how a value, a
term or a decision was arrived at. When a note and a shipped file disagree, the shipped file is
right: `docs/api/body-frame.md`, "Precedence for values", sets the order.

A number in a note is only as good as the mark beside it. A value marked `(estimate)` is a reading
of a published image or a derivation from a sourced ratio. A value marked `(unverified)` comes
from a page the writer could not open. Both marks travel into the records, where the info card
shows them per row.

## The other files in this directory

`*.draft.json` holds the machine-readable form of the note beside it. `stages.draft.json` and the
five `03*.draft.json` files are superseded by `src/data/stages.json` and
`src/data/structures/*.json`; `morphometrics.draft.json` is the table of note 05.
`zebrahub-crosswalk.draft.json` is the shipped crosswalk that note 11 describes. The `.py` files
are the check scripts of notes 02, 03 and 07, and the builders of the 03b and 03d drafts. None of
these files reaches the built app.
